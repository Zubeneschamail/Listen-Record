# 闻录：Windows 双音源实时转写与问答

![闻录图标](assets/logo-32.png)

支持同时读取 Windows WASAPI 系统回环与麦克风输入，无需安装虚拟声卡。浏览器、微信等应用通过选定输出设备播放的声音显示在左侧浅蓝气泡，麦克风声音显示在右侧浅灰气泡。按音源区分，不识别对方姓名，也不区分系统音频中的多个说话人。识别在本机 CPU 上运行，音频不上传。

## 使用

1. 本机已安装好环境后，双击 `start.cmd`。新电脑先安装 Python 3.12，再运行 `setup.cmd`。
2. 打开「设置」，默认采集“系统声音 + 麦克风”。分别选择系统播放设备和麦克风；也可切换为“仅系统声音”或“仅麦克风”。缺少输入设备时，可选择仅系统声音继续使用。
3. 选择模型和语言，点击「开始转写」，然后播放声音。首次使用尚未缓存的模型需要联网下载，等待状态变为「正在监听」。
4. 点击「悬浮字幕」可显示置顶字幕；点击「停止」会处理完已采集音频。
5. 可复制全文、导出 TXT 或带时间戳的 SRT。识别结果还会自动保存至 `recordings/` 下的 TXT 和 JSONL 文件；不保存原始音频。

转写区域采用简洁白色对话底、左浅蓝、右浅灰的短侧角圆角气泡（不显示姓名，仅保留浅色时间），临时文字以浅色显示并在原气泡内修正。主窗口采用浅灰底、白色回答区与蓝色强调色（RGB 0, 122, 204 / #007ACC）；转写和回答各自提供顶部复制按钮，时间戳以浅色独立显示，空白回答区仅显示简短提问提示。主窗口为 560×380 的无边框小窗，拖动顶部移动，拖动右下角调整大小。设置、复制、刷新、更多、最小化和关闭使用主题蓝线性图标，悬停或键盘聚焦显示名称，复制成功显示勾号。顶部提供最小化与关闭；「设置」弹窗集中显示音源、模型、语言和热词，不改变主窗口布局；点击完成、关闭按钮或 Esc 返回；底部「···」提供导出、悬浮字幕、置顶和清空。

两侧正文使用无箭头的细圆角滚动条，内容不足一屏时自动隐藏。滑块悬停时加深、拖动时变蓝，支持拖动、点击轨道和鼠标滚轮；显示与隐藏不会改变文字区宽度或重新换行。

**全局快捷键：Ctrl+空格**，在其他应用前台、闻录后台或最小化时均可开始 / 停止转写。启动后即可使用；停止时立即停止采集并补完剩余转写。收尾过程中重复按键会被忽略，按住不放不会连续触发。设置、文件导出等模态对话框打开时暂停响应。退出闻录后释放快捷键；若组合键被其他程序占用，顶部会显示「快捷键不可用」，在设置中查看原因。关闭窗口会退出程序，需保持运行或最小化才能响应快捷键。

界面和 TXT 的时间戳使用音频采集时的本机系统时间，JSONL 额外保留完整日期、时区。复制全文只有正文，无时间戳。SRT 保留从本轮采集开始计时的相对时间，便于字幕播放对齐。

每次开始创建独立记录，此前记录保留在磁盘。JSONL 记录保留 `source`（`system` / `microphone`），恢复后保留左右角色；旧记录按系统声音展示。启动程序不会自动开始采集。两路共用一个 Whisper 模型，分别维护切段和上下文；双路同时说话会增加推理负载，不承诺固定三秒延迟。使用扬声器时麦克风可能再次收到电脑声音，推荐使用耳机避免回声；本版不做声学回声消除。

**Ctrl+Backspace**：在闻录窗口内清空当前转写、草稿和问答，同时取消未完成的回答。已保存的 TXT / JSONL 不删除；正在转写时可继续接收后续文字，自动保存仍保留本轮完整记录。底部「··· → 清空当前对话」执行相同操作。该组合键不全局占用，不影响其他软件的文字编辑。

## Codex 点击问答

开启顶部「问答」后，主窗口变为左右分栏，分隔线可拖动。左侧保留转写，点击某一句会高亮它并在右侧生成回答。在单个气泡内拖选部分文字，再点击右侧「发送所选」；跨气泡的问题使用 Ctrl 多选；时间戳不会包含在问题中。关闭问答恢复单栏，转写内容保留。

按住 **Ctrl+鼠标左键** 可逐条选择不相邻的问题，再点「发送 N 条」一次发送给 Codex。再次 Ctrl 点击可取消该条选择；按原文顺序合并，仅发送一条请求。选择过程中不会发请求。发送后自动清除气泡高亮、文字选区和多选计数，右侧继续保留本次问题及回答。普通单击恢复单句直接回答；清空对话或关闭问答会清除多选。超过 2400 字会提示减少选择，不会静默截断问题。

仅主动点击提问时才发送文字，不再自动检测提问。切换到另一问题会取消旧请求，旧答案不会覆盖新问题；本轮已经回答的问题可点击直接查看缓存。右上角「复制」仅复制当前答案，左下角「复制全文」仍只复制转写。问答另存为对应的 `.qa.jsonl`。

使用本机 Codex CLI 已登录的 ChatGPT 账号，无需另填 API Key。**请求会联网发送选中文字及其附近的前文，并消耗账号额度。** 语音识别仍在本地，原始音频不上传。最多发送 2400 字问题及最近 12 段、合计 5000 字背景。开始新转写、关闭问答或退出都会取消旧请求；已经发送的内容无法撤回。

答案需等待 Codex 在线推理，并非逐字流式返回。网络、登录、额度或超时问题会显示在右侧，可再次点击问题重试。每次问答为独立请求，不携带完整聊天历史，也不会自动联网检索实时资料。CLI 使用临时空目录，禁用用户配置、项目指令、shell、浏览器和插件等工具，仅进行文本问答。

## 模型与限制

本版参考 [VibeVoice 的热词与长上下文设计](https://github.com/microsoft/VibeVoice/blob/main/docs/vibevoice-asr.md)，在现有 faster-whisper 上实现识别提示；**当前仍使用 Whisper，没有部署或宣称运行 VibeVoice 模型**。

- 设置中的「热词」支持逗号、分号或换行分隔，默认提供大模型、LangChain、LangGraph、MCP 等技术术语。开始转写时保存到本地 `recognition-settings.json`，清空输入可关闭热词；配置不上传 Git。最多 24 项、总计 256 字符。
- 正式识别使用最近 3 段、最多 160 字符的确认文字作为提示，超过 20 秒无相关语音后重置。临时字幕不写入上下文；新转写和清空对话也会重置。提示可能引入偏差，热词应只填写当前声源相关内容。
- 仅对热词表里明确列出的英文术语统一大小写和空格，例如 `lang chain` → `LangChain`。不做模糊同音替换，也不保证“大模形”等错误必然被修正。
- 正式字幕在低积压、足够快时使用 beam 3；积压达到 0.5 秒或平滑推理耗时达到音频时长的 65% 时切回 beam 1。草稿始终使用 beam 1，慢机器上更新等待会从 2 秒自适应延长，最多 6 秒，以减少重复解码。

- `small`：默认，优先中文准确度；`base` 更轻量；`tiny` 更快。均使用 CPU int8，不要求配置 CUDA。中文统一转为简体。
- 讲话过程中，草稿直接以浅蓝色显示在正文末尾，约积累 1.6 秒人声后开始识别；更新时原位替换，句末确认后换成正常颜色的正式文字，不再显示独立草稿框。完成一次草稿识别后，至少间隔 2 秒再更新。草稿不写入记录、不参与「复制全文」、导出或问答选择。停留在底部时自动跟随，向上浏览历史时不抢滚动位置。悬浮字幕仍标注临时状态。
- 使用本地 Silero VAD 检测人声，约 600 毫秒停顿后用完整片段确认文字；连续讲话最长 15 秒，优先在最近短停顿切段。必须强制切开时保留 0.8 秒重叠，并使用词时间戳去重、延后提交边界尾词。停止时补完尾段。出现积压或停止时优先处理正式转写，不生成新草稿；仍需模型运算时间，模型自身的识别错误也可能存在。
- 默认中文；英语可显式选择。自动检测在极短音频上可能判断错误。
- 同一输出设备的多个应用会被混合采集，建议一次播放一个声源。本版不按应用进程隔离音频。
- 切换耳机/扬声器后，请停止并刷新设备。部分受保护音频或独占输出可能无法回环采集。
- 请保持正常的播放音量；静音/极低音量可能导致无法识别。背景音乐、噪声、多人重叠、专有名词会影响结果。
- 若处理积压超过 60 秒或底层报告采集丢帧，程序会明确报错并停止，避免静默丢弃音频。
- 模型下载失败时可查看 `app.log`；网络恢复后重试。已缓存模型可离线使用。

## 开发与验证

应用图标位于 `assets/wenlu.ico`，包含 16–256 像素的十种独立渲染尺寸，小尺寸声波加粗并对齐像素边缘，避免多次缩放造成模糊；`assets/logo.svg` 为矢量原稿。`tools/make_icon.py` 可重新生成 PNG 和 ICO，需要开发环境安装 Pillow，应用运行本身不依赖 Pillow。Logo 沿用界面蓝色，以对话气泡和声波表示声音转文字。

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe verify_model.py --model small --language zh
.\.venv\Scripts\python.exe verify_model.py --model small --language zh --streaming
.\.venv\Scripts\python.exe smoke_test.py
.\.venv\Scripts\python.exe benchmark_recognition.py
```

`smoke_test.py` 会用 Windows 语音合成播放固定测试语句，验证真实系统回环采集、模型转写与停止收尾。执行时不要同时播放其他音频。

`verify_model.py` 使用本机语音合成创建临时测试音频后离线识别，不播放声音，不干扰当前转写。

`benchmark_recognition.py` 使用固定中文/中英混合合成语音对比原始 beam 1 与热词、上下文和自适应解码，输出文字、耗时及忽略标点大小写后的字符错误率到 `recordings/recognition-benchmark.json`。不播放声音、不上传音频。它是可复现的冒烟对比，不能代表真实课程、噪声或多人场景的整体准确度；也不是 Whisper 与 VibeVoice 模型之间的对比。

实现参考：[WASAPI 回环采集](https://learn.microsoft.com/en-us/windows/win32/coreaudio/loopback-recording)、[PyAudioWPatch](https://github.com/s0d3s/PyAudioWPatch)、[faster-whisper](https://github.com/SYSTRAN/faster-whisper)。
