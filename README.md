# 闻录使用说明

## 安装与启动

1. 在 Windows 电脑上安装 Python 3.12，双击 `setup.cmd` 安装依赖并下载模型。
2. 安装完成后，双击 `start.cmd` 启动。以后直接运行 `start.cmd` 即可。

## 声音转写

1. 点击右上角设置图标，选择「系统声音 + 麦克风」「仅系统声音」或「仅麦克风」。
2. 选择对应设备。系统播放设备需与浏览器、微信等应用实际使用的输出设备一致。
3. 选择模型和语言：`small` 优先准确度，`base` 更轻量，`tiny` 更快。首次使用未下载的模型需要联网。
4. 可在「热词」中填写当前内容涉及的专有名词，用逗号分隔。
5. 点击「开始转写」。系统声音显示在左侧浅蓝气泡，麦克风声音显示在右侧浅灰气泡；浅色临时文字会自动修正。
6. 点击停止按钮结束采集，等待剩余文字处理完成。

同时采集两路声音时，建议使用耳机，避免麦克风重复录入电脑播放的声音。更换音频设备后，先停止转写，再到设置中刷新并重新选择设备。

## Codex 问答

先安装并登录本机 Codex CLI，再开启顶部「问答」。

- **单句提问**：点击一条气泡，右侧直接生成回答。
- **部分文字提问**：在单个气泡内拖选文字，点击「发送所选」。
- **多条合并提问**：按住 `Ctrl` 逐条点击气泡，再点击「发送 N 条」。再次按住 `Ctrl` 点击可取消选择。
- **复制回答**：点击回答区右上角的复制图标。

发送后自动取消选中。问答会联网发送所选文字及附近前文，并消耗已登录 Codex 账号的额度；语音转写在本地运行。

## 复制与保存

- 转写区右上角的复制图标可复制全文，不包含时间戳。
- 底部「···」可导出 TXT / SRT、开启悬浮字幕、置顶或清空当前对话。
- 转写结果自动保存到 `recordings/`，清空当前对话不会删除已保存的记录。
- 界面与 TXT 使用电脑系统时间；SRT 使用本轮转写的相对时间。

## 快捷键与窗口操作

| 操作 | 方法 |
| --- | --- |
| 开始 / 停止转写 | `Ctrl + 空格`，后台或最小化时也可使用 |
| 清空当前对话 | 在闻录窗口内按 `Ctrl + Backspace` |
| 移动窗口 | 拖动顶部标题栏 |
| 调整大小 | 拖动窗口右下角 |

使用全局快捷键时需保持闻录运行，设置等弹窗打开时暂不响应。若显示「快捷键不可用」，请关闭重复运行的闻录或占用该组合键的程序，再重新启动。
