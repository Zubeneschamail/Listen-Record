# 闻录使用说明

## 安装与启动

- **安装包**：运行 `Wenlu-Setup-版本号.exe`，安装后从桌面或开始菜单打开闻录，无需安装 Python。
- **GPU 加速**：有 NVIDIA 显卡时，在安装组件页面选择「GPU 加速安装」或勾选「GPU 加速组件」。离线安装包已包含 CUDA 12 / cuDNN 9 组件，安装时无需联网下载，也无需另装 CUDA Toolkit；显卡需已安装 NVIDIA 驱动。不勾选则使用 CPU 转录，之后可重新运行安装包补装，升级会记住组件选择。
- **首次使用**：安装包内置 `small` 多语言转录模型，安装后选择音源即可离线转写，无需另行下载。其他模型可在「设置 → 转录 → 转录模型」中下载或切换；源码运行时需下载模型或使用已有缓存。
- **中文准确识别**：完整版离线包可选装「中文准确识别」组件，安装后在模型管理选择 `qwen3-asr · 中文准确`。它使用独立的 Qwen3-ASR-0.6B 与词时间戳模型，偏重中文及中英技术术语，速度较慢；需要支持 BF16 的 NVIDIA 显卡，建议 8 GB 显存。组件内含运行环境，无需安装 Python 或 CUDA Toolkit。普通热词不参与该模型解码，`密等性=幂等性` 等纠错规则仍生效；Whisper 模型继续支持普通热词提示。未安装时，模型管理会显示安装说明。
- **完整版数据文件**：准确版安装包由安装 EXE 和多个 `.bin` 数据文件组成，请将它们完整保留在同一文件夹再运行 EXE；安装过程无需联网。升级会保留已保存的模型选择。
- **旧版补装 GPU 组件**：可下载 [GPU 离线组件包](https://github.com/Zubeneschamail/Listen-Record/releases/tag/gpu-offline-cu12.4-cudnn9.1)，退出闻录后运行，选择包含 `Wenlu.exe` 的安装目录；重启后在设置中检测 GPU。离线包不需要 Python 或联网，不包含 NVIDIA 驱动。新版离线主安装包也可直接补装；CPU 模式重装/升级若移除了组件，需再次补装。
- **更新**：启动后会检查新版本，也可在「设置 → 数据 → 关于与更新」中手动检查。安装前会停止转写并保存记录。
- **源码运行**：安装 Python 3.12，将项目 ZIP 全部解压，再运行 `setup.cmd`，完成后运行 `start.cmd`。不要直接在 ZIP 中运行脚本。

每次启动都会以覆盖主窗口的加载动画自动检查「转录模型」「GPU 加速」「答疑模型」，显示各项进度。转录模型和 GPU 会实际执行测试推理；Whisper 的 GPU 不可用时也会验证 CPU。中文准确模型只支持 GPU，不可用时请切换 Whisper 模型。答疑模型使用当前已选择并保存的服务配置发送一条简短测试请求，仅要求回复 OK，不附带录音、剪贴板或历史对话，会消耗少量 API 额度。

全部通过后自动进入主界面。异常时会打开模型管理、GPU 设置或当前答疑服务的配置；多个异常按顺序引导，可在对应设置项重新检测。关闭异常设置可继续使用可用功能。检测有超时限制，可随时关闭应用；加载动画适配浅色和深色主题。检测通过仅代表该功能可用，开始转写后才显示当前实际加载的模型和设备。

模型服务和模型管理窗口支持按 `Esc` 取消并返回设置，关闭后恢复原输入位置的键盘焦点；再按 `Esc` 可关闭设置。取消不会保存配置草稿，模型下载期间按 `Esc` 会停止下载。

## 手动分段

转录中按 **Ctrl + Shift + 空格**，或默认的 **鼠标侧键 1（后退）**，定稿当前已采集的内容并另起一段，录音继续。双音源会一起分段；不会清空文字，也不会重新加载模型。在「设置 → 转录 → 手动分段」可将鼠标触发改为侧键 2（前进）或关闭，保存后生效。侧键只在转录期间接管，空闲时保留原来的前进／后退功能。

操作会排在当前队列中已采集的音频之后，仍需等待模型推理；有积压时不会跳过或丢弃音频来立即出字。正在处理分段时重复按键合并为一次请求。建议在语句末尾按下，直接从一个词的中间切开仍可能影响识别。回声消除尚未送出的少量音频会进入后续段落。分段沿用现有自动答疑逻辑，不直接触发额外问题。

## 声音转写

点击开始后先连接采集设备，模型加载期间已采集的音频暂存在内存中，界面显示「音频暂存中…」，就绪后继续处理。此时停止仍会收尾已采集的声音；缓存有限，溢出或采集异常会明确报错并停止，避免静默丢字。

重复开始、停止录音会保留已加载模型，便于继续练习；切换模型和退出时会等待推理结束并释放资源。

**外放回声消除**：在「设置 → 转录 → 声音来源」勾选「外放回声消除」并保存，下次开始转录时生效，默认关闭并记住选择。仅“系统声音 + 麦克风”模式使用所选播放设备的系统音轨作为参考，在本机通过 WebRTC AEC3 处理麦克风；系统音轨保持原样。请确保所选系统播放设备就是实际外放的音响，使用耳机时建议关闭。处理在独立线程中进行，音频对齐最多等待约 120 ms（不含原有采集和转录耗时）。开启时麦克风不再使用原有的强自动增益，避免放大残余回声。声音过小可调整系统麦克风音量。组件加载或运行失败会明确报错并停止本轮转录；关闭开关可恢复原有采集方式。消除效果受房间、音量、设备和同时说话影响，不能保证完全消除。

在设置中勾选「深色模式」可立即切换主题，重启后会记住选择；取消勾选恢复浅色。

1. 点击右上角设置图标，选择「系统声音 + 麦克风」「仅系统声音」或「仅麦克风」。
2. 选择对应设备。系统播放设备需与浏览器、微信等应用实际使用的输出设备一致。
3. 点击「识别」旁的模型名称打开统一的模型管理窗口，查看内置、已下载和使用中状态，下载或切换模型。下载时显示百分比和已下载 / 总大小，支持取消和重试；下载后点击「使用此模型」。`small` 更轻量，`large-v3-turbo` 适合尝试更强的识别模型。语言在设置中单独选择。
4. 可在「热词 / 纠错」中填写当前主题的专有名词，用逗号分隔，例如 `LangChain, PostgreSQL, C++, .NET, 幂等性`。带符号的英文术语会恢复指定大小写和空格。反复识别错误的词可写成 `密等性=幂等性`，只纠正识别后的输出，不自动改变模型提示；如需同时提示模型，可另加独立的 `幂等性` 热词。英文别名忽略大小写，并避免替换其他单词内部的相同字母。纠错规则优先于拼写规范化，删除规则即可关闭。请只填当前主题相关的少量词，避免无关热词干扰；保存后下次开始转写生效。
5. 点击「开始转写」。系统声音显示在左侧浅蓝气泡，麦克风声音显示在右侧浅灰气泡；连续讲话会实时更新在同一气泡中，停顿约 0.8 秒或切换音源后形成段落；较长内容会优先在句末分段。浅色临时文字会自动修正，停止转写时保存剩余段落。
6. 点击停止按钮结束采集，等待剩余文字处理完成。

连续讲话中的短停顿会先确认是否还有下一段语音，再完成切段，避免把同一句话拆得过碎。临时文字仍会更新；自动答疑在该路剩余文字定稿后继续等待稳定，再提交问题。

中文准确模型会为极短的语音开头多保留约 0.6 秒确认时间，让紧接着的后文参与识别，减少缺少上下文的误写。单独短答可能稍晚定稿；停止转写仍直接收尾。Whisper 模型保持原有切分节奏。

模拟面试时，可在「设置 → 转录 → 热词 / 纠错 → 面试术语」选择 AI / 大模型、后端开发、前端开发或 GIS / 三维，添加对应术语后保存。已有纠错规则优先保留，不会自动开启任何词库；更换面试方向时可先删除不相关的旧词。词库只是识别提示，同音词仍可能出错，可补充具体的「错词=正确词」规则。

面试中夹杂英文术语或整段英文时，可在「识别语言」选择「自动检测」，让模型保留原话语言；固定「中文」有时会把英文口语输出为中文。自动检测也可能误判，建议用自己的典型录音比较；更改语言并保存后，下次开始转写生效。

热词按填写顺序优先保留。超过识别模型的提示长度时，会移除末尾的完整术语，避免把 `PostgreSQL` 等名称从中间截断。纠错规则只处理输出，长规则不会截掉正确词的后半部分。词库总长度仍受限制，重要的自定义词和纠错规则宜放在前面。

开始转写会读取当前已保存的热词和纠错规则，避免旧界面内容覆盖后来保存的规则。词库无法读取时会提示，原文件保留；可在设置中核对并修改后保存，再重新开始。只改外观或其他设置时，不会重写未编辑的词库；如果编辑词库期间文件被其他操作更新，保存会提示核对，并保留当前草稿。

连续讲话到达切段上限后，如果马上停止或停顿，过短的收尾音频会补入前面已经采集的语音，最多组成约 2.4 秒上下文再识别，减少句末中文和英文术语缺少上下文的问题。补入部分按原时间戳去重；正常长片段仍沿用原有重叠长度，无需改设置。模型仍可能听错，可通过修改转录及「热词 / 纠错」补充具体术语。

同时采集两路声音时，建议使用耳机，避免麦克风重复录入电脑播放的声音。更换音频设备后，先停止转写，再到设置中刷新并重新选择设备。

应用优先使用可用的 NVIDIA 显卡，初始化失败时自动改用 CPU，状态栏会显示实际使用的设备。基础安装包默认支持 CPU；源码版可运行 `.\.venv\Scripts\python.exe -m pip install -r requirements-gpu.txt` 安装 GPU 运行库。

在「设置 → 音频与转录 → GPU 加速」点击「检测加速」，可检查 CUDA 设备、运行库，并使用当前所选本地模型实际执行一次 GPU 推理。只有推理成功才显示检测通过；失败会列出无法加载的 DLL 或模型、驱动等错误。检测在独立进程中执行，最长等待 120 秒，无需联网。请先停止转写再检测；开始转写或退出应用会取消检测。设置中另行显示已加载转写模型的实际 CPU/GPU 状态，检测通过不会自动切换正在使用的模型。

## 模型问答

AI 答疑面板启动后默认显示。在「设置 → 模型服务」选择并保存问答服务：

- **DeepSeek**：填写 DeepSeek 开放平台的 API Key；默认 `deepseek-flash`，关闭深度思考并流式显示答案。
- **兼容 API**：填写服务商的 API 地址、模型名称和 API Key。支持 OpenAI Chat Completions 流式接口，地址需包含服务商指定的路径（如 `/v1`）。更改地址后需重新填写密钥。

API Key 加密保存在当前 Windows 用户的本机数据目录。API 调用按服务商规则计费。

**账户余额**：在「设置 → 答疑 → 账户余额」点击「查询」，显示 DeepSeek 官方返回的当前可用余额及更新时间，按原币种展示，不做汇率换算。无需设置预算，不显示百分比或进度条。查询失败会清除旧金额并提示原因，可重新查询；切换服务或密钥后需重新查询。查询仅使用已保存的 DeepSeek API Key，不发送对话内容；兼容 API 暂不支持。

在「设置 → 答疑 → 检查连接」中验证所选服务。检测会发送一条不含转写内容的测试请求，消耗少量额度；成功收到响应才显示“响应正常”。开启问答时仅检查登录或配置，不发送测试请求。

- **单句提问**：点击一条气泡，右侧直接生成回答。
- **直接输入**：在右侧底部输入问题，点击纸飞机或按 `Enter` 发送，`Ctrl + Enter` 换行；与当前历史问答共用上下文。连接异常或内容超过 2400 字时保留草稿。
- **Markdown 显示**：右侧对话支持标题、粗体、斜体、删除线、列表、引用、行内代码、代码块、链接和表格；窄面板中的宽表格按字段分行展示。复制按钮保留原始 Markdown，输入和编辑问题时仍使用原文。
- **流式阅读**：生成回答时仅更新变化的末尾，合并同批次刷新；向上滚动阅读时保留当前位置和未变更文字的选区，回到底部后继续自动跟随。
- **联网答疑**：模型可按需搜索公开网页、读取链接正文，并在回答旁附上来源链接。明确要求联网、查询最新信息或提供网页链接时先查阅；普通概念题不强制联网，说“不要联网”可禁用本轮网页工具。无需额外搜索密钥，**仅使用360搜索**，最多等待 4 秒。无法访问、超时、需要验证或没有相关结果时，直接在对话中说明本次未能完成联网查证并结束本次回答，不自动重试、不切换搜索服务、不让模型继续补答。可以稍后重试、调整关键词或提供具体网页链接。相关性过滤只排除明显偏题，不替代事实核查。兼容 API 需支持工具调用。仅发送必要搜索关键词，网页请求不携带模型密钥、本机登录态或 Cookie。支持 HTML 和文本页面、长文分段读取，不执行 JavaScript，不访问本机或内网；登录页、动态页面或超过 2 MB 的页面可能无法读取，失败时会说明实际情况。连接检测和 Flash 图片提取不调用网页工具。
- **上下文占用**：输入区发送按钮左侧默认只显示圆环，鼠标悬停时在圆环左侧显示百分比，不弹出提示框；统计最近一次请求的输入与输出 Token。优先使用接口统计，尚未返回统计时以 `≈` 标注本地估算；不会累加多轮工具调用或 Flash 读图用量。按压缩后实际发送的历史统计，不含未发送草稿与后续新增转写。DeepSeek 官方 Flash / V4 Pro 按[官方模型容量](https://api-docs.deepseek.com/quick_start/pricing)计算；未知模型或第三方网关显示 `—`，不猜测容量。清空对话、切换服务时重置。
- **粘贴图片**：在输入区按 `Ctrl + V` 粘贴剪贴板图片，预览右上角的 `×` 可移除图片。可补充文字或直接发送图片，无需开启自动答疑；每次附带一张图片，再次粘贴会替换待发送图片。
- **调整输入区高度**：上下拖动右侧回答区与输入区之间的细分割线，松开后应用高度；收起再展开会恢复调整后的高度。
- **展开 / 收起输入框**：在输入框中按 `Esc` 收起。收起后只显示添加和发送按钮，草稿保留；点击两按钮之间的空白区域展开。无草稿、无所选内容时，点击发送按钮也会展开输入框。
- **部分文字提问**：在单个气泡内拖选文字，点击发送按钮。
- **多条合并提问**：按住 `Ctrl` 逐条点击气泡，再点击「发送 N 条」。再次按住 `Ctrl` 点击可取消选择。
- **修改问题**：单击右侧问题即可原位编辑并直接输入，`Ctrl + A` 只选中编辑框中的问题；点击纸飞机或按 `Enter` 发送，`Ctrl + Enter` 换行。原问题与回答会被覆盖，按 `Esc` 取消。
- **复制回答**：点击回答区右上角的复制图标。
- **自动回答**：开启标题栏右侧的自动答疑图标，同时监听剪贴板，并自动结合本次会话全部转写和历史 AI 回复回答新出现的问题。除了疑问句，以「介绍一下」「说一说」「讲一下」等方式提出的口头指令也会触发答疑。短会话使用完整内容；长会话保留近期原文，并从早期内容抽取摘要和相关片段。编辑后的问答以最新版本为准。只处理定稿文字，不追答开启前的旧问题；关闭后取消自动请求。此模式会向当前 AI 服务发送相关文字并消耗对应额度，服务报错时暂停发送，检查连接恢复后继续。

在「设置 → 答疑 → 面试官音源」指定哪一路声音可以提出问题。默认「自动（优先系统声音）」：双路采集时只将系统声音作为面试官，仅采集麦克风时自动使用麦克风；也可明确选择系统声音、麦克风或两路声音。另一方的转录仍保留为上下文，不会拼接进待答问题。选择两路声音时，两路问题分别排队。修改后保存生效，更换面试官音源会清除旧音源的待答问题并取消正在生成的语音自动回答，已完成的问答保留。

双路采集时，一路结束播放、停止送入音频后，即使另一路仍在采集静音或讲话，也会独立完成空闲音源的剩余转写。自动答疑在该路定稿文字到齐并稳定后继续，不必先停止整轮录音；如果转录积压，仍会先处理已经采集的音频。

自动答疑等待对应音源停止讲话、末尾定稿文字到齐并稳定约 1.5 秒再发送，不再因为问题持续超过 6 秒而提前提交。支持「举个具体例子」「设计一个订单系统」「手写一个缓存」「对比一下」等口头指令；已有问题后，也支持「再具体一点」「继续」等简短追问。相同音源、上下文未变化时，8 秒内的重复定稿会被忽略；候选人给出新回答后可以再次提出相同的问题。剪贴板、截屏和手动发送继续按各自入口处理，不受语音结束等待影响。

AI 正在回答或连接暂不可用时，已经说完并稳定的语音问题仍会分别排队，最多保留 8 道，恢复可用后按顺序回答。每题只使用其定稿排队时已有的转写背景，并承接发送前已完成的历史回答，后面新说的题目不会混进前题。排队中的转录仍可修正；首次提问还在排队或已重新载入历史问答时，“再具体一点”等简短语音追问也能承接前文。超过队列上限会提示该题未自动发送，原转录保留，可点击对应气泡提问。关闭自动答疑、清空会话或更换面试官音源会清除待答语音；明确手动提问会替换待答语音，剪贴板问答继续与语音轮流处理。

重复问题判断和长语音重叠拼接会保留术语中的关键符号，区分 `C++`、`C#`、`C`、`.NET` 等名称；大小写、全角形式和句末问号的变化仍按同一句处理。此规则只防止误去重，不会自动把听错的术语改成另一种语言或技术。

发送后自动取消选中。手动问答、剪贴板问答与转录自动答疑 共用当前会话，可以承接「要的」「继续」「换一种写法」等追问。DeepSeek 和兼容 API 按 `user → assistant → user` 的消息顺序续接对话。同样的问题会结合最新上下文重新回答。手动问答另带所选文字及附近前文；转录自动答疑另带会话转写，剪贴板问答不附加无关录音。长会话保留近期完整消息，并将早期内容和转写压缩为相关背景，限制请求长度；语音转写在本地运行。切换模型服务会取消正在生成的回答，已完成的对话保留。使用 `Ctrl + Backspace` 清空对话时同时清除本轮上下文。

## 剪贴板自动问答

**面试话题切换**：独立的技术问题优先按本题选择上下文。问完 Agent / Code Review 再问高并发、事务或数据库时，会筛除明确不相关的历史 AI 回答，并优先匹配简历里的后端业务经历；用户原话和转写仍保留。只有“刚才那个项目”“那怎么处理”等需要前文的追问才补入前题做知识包检索。话题识别是保守规则，未识别的主题仍依赖模型判断，模型回答需自行复核。

明确说“回到 Code Review”等话题时，会找回该话题的问答，而不是拼接最近两题。常规技术面试题默认不联网，明确要求搜索、最新信息或提供链接时仍联网。普通口头回答超过350字符时最多精简一次；详细回答、代码和图片题保留展开空间。模拟经历允许按使用者授权合理补全实现细节，事实查证仍区分资料证据和模拟设定。

1. 配置好模型服务后，开启标题栏右侧的自动答疑图标，或在「设置 → 答疑 → 自动答疑」勾选「自动读取转录问题和剪贴板」。无需开始录音。
2. 在其他应用复制文字或截图，内容稳定约半秒后自动发送给当前 AI，回答显示在右侧。图片会在右侧显示缩略图，AI 识别结果或回答接在图片下方；没有问题时概括要点。缩略图随面板宽度缩放，后续追问时保留。
3. AI 正在回答时，新内容按顺序排队（最多 8 条；超出会提示跳过）。关闭开关会停止两种自动输入、清空队列，并取消正在生成的自动回答。

只处理开启后的新内容，忽略闻录自身的复制操作与连续相同内容。文字最多 2400 字；图片最多 2500 万像素，长边缩至 4096 像素后 PNG 不超过 8 MB。支持剪贴板中的位图 / PNG 截图，不读取复制的文件列表。快速连续复制时仅处理稳定下来的最新内容。

**图片服务**：支持 DeepSeek 的 `deepseek-flash`；兼容 API 需要配置具备图片理解能力的模型。DeepSeek 图片输入使用官方支持的 `image_url` 内容块（[图像理解文档](https://api-docs.deepseek.com/zh-cn/guides/vision/)）。图片只用于当前请求；本轮对话在内存中保留图片预览，清空对话或退出后释放；保存的历史记录只有图片说明与答案，不保存原图，图片问题需重新复制发起。

**Flash 读图 → Pro 分析**：在模型服务中选择 DeepSeek 的 `deepseek-v4-pro` 后，图片自动先发给 `deepseek-flash` 提取文字、公式、表格和视觉关系，再将识别结果及原始问题交给 Pro 分析。界面依次显示「Flash 正在读图」「读图完成，Pro 正在分析」，只将 Pro 的最终回答作为答案显示和保存。两步使用同一 API Key，分别计费，共用本次请求的超时与取消控制；Flash 失败或被取消时不会继续调用 Pro。Pro 可以继续使用已启用的参考资料，Flash 不查阅本机资料。文字问题仍直接发送给 Pro；选择 `deepseek-flash` 时图片仍由 Flash 直接回答。Pro 根据文字描述推理，识别遗漏或模糊处可能影响答案。

Flash 读图结果在整轮分析成功后保留在当前会话内存中，后续文字追问会连同历史问答一起发送，无需再次读图；识别文本作为可能有误的参考资料，不作为指令。清空对话或退出会清除这份上下文，原图不会保存在会话中。直接使用 Flash / 兼容 API 的图片问答，后续只能参考已生成的文字答案，无法重新查看原图。

开启后，新的剪贴板文字或图片及相关历史问答会发送到当前服务并消耗额度，不附加无关语音转写上下文。转录与剪贴板共用一个自动答疑开关；切换录音模式或模型服务不会关闭监听。AI 忙时排队，语音问题与剪贴板内容依次进入同一段对话。请求失败时继续监听，待检查模型连接恢复后发送队列中的内容。手动关闭开关或退出程序才停止监听，重启后需手动开启。

## 添加参考资料

1. 在「设置 → 答疑」选择并配置 DeepSeek。
2. 点击 AI 区域左下角的「+」，选择「添加文件」或「添加文件夹」，再在 Windows 选择器中选择资料。添加后默认启用；可在「设置 → 资料」管理资料或关闭查阅。
3. 像平常一样手动提问或开启自动答疑。DeepSeek 会按问题搜索、分段读取资料，并在回答中标注文件路径和行号。列表中的 `r1`、`r2` 对应引用中的资料根目录。
4. 选中资料后点「移除」只取消引用，不删除原文件。文件变更会在后续请求中重新读取。

支持文本、Markdown、代码、CSV、JSON、可提取文字的 PDF 和 DOCX。文本文件最大 2 MB；PDF / DOCX 最大 20 MB，PDF 最多 100 页，扫描件请先做 OCR。更大的文档可按章节拆分。

添加资料后答案仍逐步显示；必须先查阅的问题会在实际取得资料后输出答案。已解析文件在内存中跨提问复用，文件修改或替换后重新读取；缓存最多保留 128 个文件、约 16 MB，不写入磁盘。目录列表按页扫描，减少大文件夹的等待；复杂问题的多轮模型查阅仍会增加耗时。

使用 DeepSeek 回答工作或项目经历问题时，若直接添加的普通文件可识别为简历，闻录会先在本机读取其中的经历内容，再随本轮问题发送给模型；即使同时启用了知识包，也优先按简历中的个人事实作答。未涉及个人经历的提问不会自动附带简历。

资料保存在本机，只有目录清单与实际查阅的片段会发送给 DeepSeek；不会自动上传整个文件夹。只读工具不能修改文件或执行命令，默认跳过依赖、构建目录及常见密钥文件。单次查阅有轮数、范围和内容长度限制；大型目录建议按项目或子目录添加。

普通文件查阅仅接入 DeepSeek。DeepSeek 和兼容 API 都支持下面的知识包检索。「检查连接」不会查阅或发送任何资料。

### 导入向量知识包

**专属安装包**：客服交付的专属版本可内置客户知识包；首次启动会校验并复制到当前 Windows 用户的数据目录，自动开启查阅。之后手动停用或移除的选择会保留。安装另一客户的专属版本时替换先前安装器导入的资料引用，手动添加的资料和历史记录保留。知识包不包含模型服务密钥，AI 问答仍需配置模型服务。

1. 使用独立生成工具生成 `.wlkb` 文件。在问答区「+ → 知识包」或「设置 → 资料 → 知识包」中可一次选择多个文件；普通「添加文件」也可选择知识包。知识包仅接受 `.wlkb` 后缀；旧 `.wenlukb` 文件可直接改名为 `.wlkb`，然后移除旧路径并重新添加，无需重新向量化。
2. 添加后默认启用；在设置窗口中修改时，需要点击「保存」才生效。当前保存的是文件引用，不会删除、改写或自动复制原包，移动原包后需重新添加。
3. 像平常一样提问。闻录先用本地 BGE 模型进行语义和关键词混合检索，再将相关原文交给当前问答服务。会显示「正在检索知识包」。面试回答默认以面试者第一人称直接作答，不附资料整理说明、投递建议或检索过程；明确要求来源或查证时，再引用 `kb1/包名/资料路径`、章节和页码或行范围。
4. 单个知识包最多 8 GiB、100 万个片段，包内清单最多 64 MiB；最多同时添加 4 个包，可以属于不同客户。向量每批扫描 512 条，只读取最终命中的正文，避免整包载入内存；检索时间仍随包内片段总数增长。命中片段分别标注所属客户和知识包，回答时不应混用不同客户的个人经历。知识包增删、启用或停用后，后续问答不再自动引用此前的问答和转写；原有可见记录仍保留，明确重新选择旧文字提问除外。
5. 包文件更新后会重新读取并刷新缓存；损坏、模型不匹配或客户身份异常时明确报错，不静默使用旧包。需要无资料回答时，可以说明「不用读取资料」。「不要联网」不会关闭本地知识包检索。

安装包内置约 24 MB 的通用中文向量模型，可以离线检索；客户知识包和 demo 不随软件打包。源码用户可运行 `python prepare_knowledge_model.py` 准备模型，或使用已经暂存好的构建模型。模型版本必须与生成工具一致，首次加载会校验固定 SHA256。

**带原页图片的知识包**：部分整理包另带与片段关联的原PDF页面。闻录只读取当前命中片段关联的最多两张原页，核对日历绿色日期、排名、图形和连线等文字OCR无法表达的内容。DeepSeek Pro 按页增加 Flash 原页核对请求（最多两次），再结合题干给出答案，因此比纯文字检索稍慢并增加相应读图用量。截图提问时，识别出的题目与末尾条件会参与检索。普通纯文字包继续按原流程使用，原题与参考答案不一致或看不清的地方仍需核验。

Builder 一键导入大包时，校验和复制在后台执行，最多等待 10 分钟确认；成功保存后才返回导入成功。期间可继续操作窗口；若资料设置被修改，待导入副本会丢弃，需要重新点击导入。旧版安装包需更新后才能使用扩大的容量。

每次最多附带 8 个片段，片段 JSON 合计最多约 16 KB，计入实际请求上下文统计。仅发送命中的原文，不上传整份知识包；知识包不是已加密或已签名的文件，客户 ID 校验也不等于商业激活授权。PDF 页码和 DOCX 提取行号沿用构建工具的来源信息。

Flash 读图 → Pro 分析时，先识别提问截图，再按问题和识别文字检索知识包；包内包含命中原页图片时，由 Flash 逐页核对原图标记，最后由 Pro 结合条件回答。简短追问会参考近期用户问题构造查询；这不是完整的多轮查询改写。检索排名不保证有答案，个人经历和数字缺失时应明确说明，不能把通用知识当成客户经历。

## 复制与保存

- 转写区右上角的复制图标可复制全文，不包含时间戳。
- 修改设置后点击右下角「保存」提交；关闭窗口或按 Esc 放弃未保存的修改。主题与字号可预览，自动答疑和资料变更保存后生效；模型服务弹窗单独保存。
- **共享时隐藏窗口**：在「设置 → 外观 → 屏幕共享」勾选「共享时隐藏闻录窗口」并保存，自己仍能看到和操作闻录，支持 Windows 捕获排除的共享/录屏方式中不会显示闻录窗口，同时隐藏其任务栏入口；可从系统托盘重新打开。设置会记住，主窗口、设置、悬浮字幕及新打开的闻录弹窗同步应用；取消勾选并保存可恢复窗口及任务栏入口。需要 Windows 10 2004 或更新版本，实际效果取决于共享软件及捕获方式，共享前请检查其预览。系统输入法候选、文件选择器等系统窗口不属于此开关的覆盖范围。
- 设置分为「转录、答疑、资料、外观、数据」：音源与识别参数在转录页，模型服务在答疑页；字号、主题、置顶和悬浮字幕在外观页；导出、历史记录和更新在数据页。滚轮经过下拉框时只滚动页面，不改变选项。
- 开始、停止转写保留当前转录和问答，只有 `Ctrl + Backspace` 清空当前对话。
- 转写结果自动保存到 `%LOCALAPPDATA%\Wenlu\recordings`，清空当前对话不会删除已保存的记录。
- 打开转录记录前会核对文字、音源和时间；格式错误时提示所在行，保留当前练习及未发送草稿。支持带 UTF-8 BOM 的转录和修正文件。
- 转录可导出为 TXT 或 SRT，请使用新的文件名；导出不会覆盖当前练习及其原始自动保存的 TXT。导出中途失败时，目标位置已有的文件也会保留。
- 录音记录对应的已完成问答另存为同名 `.qa.jsonl`。在「设置 → 数据 → 打开练习」选择录音的 JSONL 时，会一起恢复问答供回看和继续提问，不会重新发送旧问题。备份或移动时请一起保留配套文件。
- **纯手动问答保存**：不用录音也可在「设置 → 数据 → 保存问答副本」保存当前已完成的问答为 `.qa.jsonl`，保留文字、顺序、记录身份和已有时间；正在生成的回答、未发送的草稿与原图不包含在副本中。请选择不同文件名，当前练习的原记录不会被副本覆盖。未主动保存且未关联记录的手动问答仍只在当前会话中。
- 导出副本不会切换当前练习或自动同步之后的新回答。要继续保存到该文件，用「打开练习」选择它：只恢复问答，之后完成的新回答追加到该文件，修改旧题也保存在该文件中。清空当前视图不会删除已存记录；开始新录音后，新问答保存到新录音的问答文件，旧题仍按各自原文件修改。
- 重复的问题和回答按各自记录区分；修改旧问题只更新所选那条。继续另一轮录音后再修改旧题，仍保存到旧题所属的问答文件。问答文件损坏或已被外部修改时会提示并保留文件，转录仍可打开，新回答仍可复制。历史图片只恢复已经保存的文字问题和最终回答，不能重新查看原图或恢复仅在内存中的读图资料。
- 每个定稿段落会追加保存到 JSONL 原文和 TXT，不随会话变长反复覆盖整份 TXT。写入失败会停止本轮采集并提示手动导出；如果仅 TXT 失败，先前写入的 JSONL 原文仍保留。
- 长语音硬切后，如果下一段识别失败或音频设备断开，退出时会保留已识别并暂存的稳定文字，仍提示原始错误；尚未确认的边界词不补写。
- 异常退出时保留的未完成段落会标注「转录中断」，JSONL 和 TXT 保留该标记。中断段落及尚未收齐的语音问题不会自动发送给答疑模型；此前已排队的完整题目保留。核对或修正文字后，可点击对应气泡手动提问。
- **修正转录**：右键已定稿的气泡，选择「修正这段转录…」，编辑后保存；`Ctrl + S` 保存，`Esc` 取消。「恢复原转录」可先还原编辑框内容，再保存撤回该段修正。修正后的气泡会标注「已修正」，复制、导出和后续问答采用修正文字；已经生成的回答保留，可重新点击修正后的段落提问。
- 原始自动保存的 JSONL / TXT 保留原文，修正单独保存在同名 `.corrections.json` 文件中。备份或移动记录时请一起保留该文件；「设置 → 数据 → 打开练习」选择录音 JSONL 后会恢复匹配的修正。原记录被外部修改、修正损坏或不匹配时会提示并显示原文，不会强行套用。录制中可修正定稿段落，打开另一份记录前需先停止转写。
- 修正当前记录不会自动生成热词规则。反复出现的错词可在修正窗口勾选「保存本段后，另存常用错词规则」：保存本段后，再明确填写完整错词和正确词，例如「密等性 → 幂等性」，点击「保存规则」。规则从下次开始转写生效，也可在「热词 / 纠错」中查看、修改或删除；取消规则窗口不会撤回已经保存的本段修正。
- 在「记住常用错词」窗口保存成功后，规则用于两路音源的后续识别，无需重新开始转录；已经生成的转录和回答需单独修正。此操作只更新输出纠错，正在转录所用的普通热词提示保持到下次开始转写。
- 同名错词已有不同规则时，需要明确勾选替换；词库满或保存失败时会提示，保留原有词库。规则独立于记录，恢复原转录不会自动删除已保存的规则。请填写完整词语，避免仅用一个常见汉字做通用替换。英文规则按完整术语匹配，保留 `file.NET`、`net.io` 等其他名称；没有模糊替换或自动训练。
- 界面与 TXT 使用电脑系统时间；SRT 使用本轮转写的相对时间。

## 本地转录评测

`tools/benchmark_transcription_accuracy.py --manifest samples.json --models large-v3-turbo --beams 3 --languages zh auto --output results` 可对同一组标注音频比较固定中文与自动检测。清单是 JSON 数组，每项包含 `audio`、`reference`，可另填 `language`、`group`、`critical_terms`；相对音频路径按清单所在目录解析。未传 `--languages` 时沿用各样本的语言。

报告保留原有字符错误率 CER，另给出按汉字和英文单词计数的混合错误率 MER，以及明确标注术语的拼写召回率。`C++` 和 `C#` 的符号差异不会再被 CER 的标点清理掩盖；术语必须实际出现在参考文本中，不能把所有热词都算作应识别内容。指标不自动判断语义、同义表达或技术答案正误，数字格式、语气词和口吃也不悄悄删除；同时保留逐条参考文本与识别结果供复核。

`tools/prepare_code_switch_samples.py --split test --output samples` 可下载固定版本 ASCEND 的少量真实中英录音和标注；支持 `validation` 分组。先按音频长度、语言、说话人和不含 `[UNK]` 标注的规则选样，再进行推理，保存来源、许可和音频 SHA256。样本仅用于本地评测，不训练模型，也不放入应用安装包；少量公开对话不能代表全部技术面试场景。

## 快捷键与窗口操作

| 操作 | 方法 |
| --- | --- |
| 开始 / 停止转写 | `Ctrl + 空格`，后台或最小化时也可使用 |
| 截屏提问 | 全局按 `Ctrl + K`，截取前台窗口所在屏幕并发送给当前 AI |
| 清空当前对话 | 在闻录窗口内按 `Ctrl + Backspace` |
| 自动问答 | 在闻录窗口内按 `F12` 开启 / 关闭自动答疑 |
| 窗口内专注模式 | 按 `F11` 让转录与 AI 区域占满当前窗口，不改变窗口大小和位置；按 `Esc` 或再次按 `F11` 恢复 |
| 移动窗口 | 拖动顶部标题栏 |
| 调整大小 | 拖动窗口任意边缘或四角，松开鼠标后更新布局；F11 模式下同样可用 |

使用全局快捷键时需保持闻录运行，设置等弹窗打开时暂不响应。若显示「快捷键不可用」，请关闭重复运行的闻录或占用该组合键的程序，再重新启动。

**Ctrl+K 屏幕提问**：默认启用，可在「设置 → 答疑 → 屏幕提问」取消勾选并保存。开启后闻录全局接管 Ctrl+K；每次按下才截取前台窗口所在的单块显示器，直接发送给当前支持图片的模型，答案显示在闻录问答区。无需开启录音、剪贴板监听或自动答疑。再次按下会用新截图发起提问并替换仍在生成的旧回答，长按不会连续发送。截图保存在当前会话内存中，不写入图片文件、不改动剪贴板；只随该次问答发送给当前模型服务并按其规则计费。多屏时按前台窗口选择显示器；图片最长边缩至4096像素，并限制在8MB内。关闭或清空对话时，尚未发送的截图会丢弃。
